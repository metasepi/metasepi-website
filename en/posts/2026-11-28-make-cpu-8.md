This talk is a gentle introduction to [Hardcaml](https://github.com/janestreet/hardcaml), an RTL design library embedded in OCaml. Rather than discussing advanced verification techniques, I wanted to share the fun of building digital circuits in an interactive programming environment.

We start with a simple 5-bit counter and do everything inside `utop`, an OCaml REPL:

- Describe a digital circuit using ordinary OCaml functions.
- Generate Verilog from the circuit.
- Simulate the circuit cycle by cycle using an ordinary OCaml `for` loop.
- Display the recorded waveforms directly in the terminal.

No FPGA, external Verilog simulator, or even a separate OCaml project is needed to try this example. I tested the installation steps and the REPL session in a Docker environment, so you can follow along with the slides.

And what happens if we keep playing with Hardcaml?

With the help of AI coding agents, I ended up building a dual-core RISC-V SoC that boots Linux 6.18 with SMP on a Colorlight i9 FPGA board.

I hope this talk encourages more people to give Hardcaml a try and enjoy building their own digital circuits.
